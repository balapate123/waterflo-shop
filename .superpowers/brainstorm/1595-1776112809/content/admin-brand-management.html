Admin Panel — Brand Management

Where should brand logo/image management live in the admin dashboard?

A

New "Brands" Tab

Add a 6th tab to admin nav: Dashboard | Users | Orders | Products | Brands | Settings. The Brands tab shows a card grid of all 8 brands — click any brand to edit its logo, banner image, tagline, color, and other metadata.

Inside Settings Tab

Add a "Brand Customization" section to the existing Settings tab, below the GST/Charges section. Each brand gets an expandable row where you upload logo, set banner image, etc.

Pros: No new tab. Cons: Settings gets busy, brand management buried.

What you'd manage per brand:

  • Logo — square image shown on brand cards and brand page header (PNG/JPG/WebP, max 2MB)
  • Banner image (optional) — wider image for the brand page hero section
  • Brand color — the primary gradient color (currently hardcoded in brand-config.js)
  • Tagline — short description shown on cards
  • Active/Inactive — toggle brand visibility
